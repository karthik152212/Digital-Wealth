=== KEY UI ELEMENTS ===

Nominee Row States:
- Invited (no claim): Invite, Edit, Revoke (3 buttons)
- Claim pending: Approve claim, Reject, Invite, Edit, Revoke (5 buttons)
- After approval: Same as Claim pending + recovery view
- After rejection: Same as Claim pending + error message

Action Buttons Flow:
1. Invite: Opens asset selector -> selects asset -> sends invitation -> claim code generated
2. Edit: Opens edit dialog -> name/relationship editable (email locked) -> Save/Cancel
3. Revoke: Removes authorization -> buttons revert to Invite/Edit (may need page refresh)
4. Approve claim: Reveals recovery view with guidance-only information
5. Reject: Shows error message, maintains interactive state
